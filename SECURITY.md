# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/utity-tools/framed/security/advisories/new).
Do not open a public issue.

Include what you found, how to reproduce it and its impact. You will get an answer within a
week. Please give us a reasonable time to fix the issue before disclosing it.

## Scope

In scope: this repository and the deployed application, including tenant isolation between
galleries, authentication, the public tag URLs and lead forms.

Out of scope: denial of service, social engineering, and findings that need physical access
to a gallery beyond tapping a card.

## Supported versions

Only the latest release on `main` is supported.
